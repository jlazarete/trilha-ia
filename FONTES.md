## Pontos de atenção

- **RAG Techniques:** a licença permite uso não comercial com atribuição e reserva o uso comercial ao autor. Por isso nenhum arquivo dele é copiado aqui. Leia a [licença](https://github.com/NirDiamant/RAG_Techniques/blob/main/LICENSE) antes de reutilizar o código em trabalho comercial.
- **Traduções da Microsoft:** são geradas de forma automatizada pelo projeto Co-op Translator, segundo os READMEs dos repositórios. Podem conter imprecisões.
- **Neural Networks: Zero to Hero:** o repositório guarda os notebooks. As aulas estão em vídeo no YouTube, em inglês. O último commit é de 2024, e o README diz que o curso está em andamento ("Ongoing").
- **Hands-On Large Language Models:** o repositório é o material de apoio do livro de mesmo nome. O texto completo está no livro.

## Como citar

Para usar um material, cite o autor e o repositório de origem conforme a licença de cada um. Para citar esta trilha, use o link deste repositório.
