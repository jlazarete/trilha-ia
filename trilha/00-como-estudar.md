# Como estudar esta trilha

A trilha reúne cursos abertos e gratuitos em uma ordem de estudo. O conteúdo em si fica nos repositórios originais. Aqui você encontra o caminho, os links e o que cada etapa pede de você.

## Regras de ouro

- **Siga a ordem dos módulos**, a menos que o módulo diga que é opcional.
- **Rode o código.** Todo módulo aponta para notebooks ou scripts. Ler sem executar rende pouco.
- **Marque o progresso.** Faça um fork deste repositório e marque os itens `- [ ]` conforme concluir.
- **Anote o que travou.** Se algo quebrou por versão de biblioteca ou mudança de API, abra uma issue com o módulo e o item.

## Quatro formas de percorrer

| Objetivo | Caminho sugerido |
|---|---|
| Entender IA do começo | Módulos 1, 2, 3, 5, 6 |
| Construir aplicações com LLMs | Módulos 6, 7, 8 (revise o módulo 5 se faltar base) |
| Aprender como redes e GPT funcionam por dentro | Módulos 3 e 5 |
| Levar projetos de ML para produção | Módulos 2, 3 e 9 |

Esses caminhos são sugestões de ordenação da trilha. Ajuste conforme a sua base.

## Idioma dos materiais

- **Microsoft (AI For Beginners, ML For Beginners, AI Agents for Beginners):** os repositórios têm tradução para pt-BR. Segundo os próprios repositórios, as traduções são geradas e mantidas de forma automatizada pela Microsoft. Quando algo parecer estranho, compare com o original em inglês, que cada item também linka.
- **Karpathy, Hands-On LLM, RAG_Techniques e Made With ML:** apenas em inglês.

## Ferramentas comuns

Os cursos usam Python, notebooks Jupyter e, em vários casos, o Google Colab. Cada repositório documenta o próprio ambiente. Siga o README da fonte, que é a referência atualizada.

## Atenção a custos e chaves de API

Alguns notebooks chamam APIs pagas ou serviços em nuvem. Antes de rodar, leia as instruções do item. Nunca publique chaves de API em fork ou commit.
