# Módulo 2: Machine Learning clássico

**Objetivo:** Aprender o ciclo básico de ML (dados, treino, avaliação) com regressão, classificação, agrupamento, PLN, séries temporais e aprendizado por reforço.

## Antes de começar

- O curso se apresenta como curso para iniciantes. Os projetos usam Python e notebooks.

**Fontes deste módulo:** [ML For Beginners](https://github.com/microsoft/ML-For-Beginners) (Microsoft, MIT).
