# Módulo 8: Agentes de IA

**Objetivo:** Construir agentes que usam ferramentas, planejam, lembram, colaboram e podem ser levados a produção com segurança.

## Antes de começar

- O README do curso diz que cada lição cobre um tópico próprio e que dá para começar de onde quiser. O guia de estudo do curso sugere ler a configuração e fazer as lições 01 a 06 em ordem.
- Para quem está começando em IA generativa, o README indica o curso complementar [Generative AI For Beginners](https://aka.ms/genai-beginners), com 21 lições.

**Fontes deste módulo:** [AI Agents for Beginners](https://github.com/microsoft/ai-agents-for-beginners) (Microsoft, MIT), [Hands-On Large Language Models](https://github.com/HandsOnLLM/Hands-On-Large-Language-Models) (Jay Alammar e Maarten Grootendorst, Apache 2.0).
