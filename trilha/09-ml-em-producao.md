# Módulo 9: ML em produção (MLOps)

**Objetivo:** Sair do notebook: estruturar, testar, versionar, servir e implantar uma aplicação de ML com CI/CD.

## Antes de começar

- Python e conhecimento básico de ML (módulos 2 e 3).
- O curso mostra instruções para rodar no laptop (local) e em clusters Anyscale. O README avisa que no laptop fica mais lento.

**Fontes deste módulo:** [Made With ML](https://github.com/GokuMohandas/Made-With-ML) (Goku Mohandas, MIT).
