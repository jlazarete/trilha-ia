# Módulo 6: LLMs na prática

**Objetivo:** Usar e adaptar modelos de linguagem em tarefas reais: embeddings, classificação, prompts, geração, busca semântica e ajuste fino.

## Antes de começar

- Módulo 5 concluído é o caminho natural. Cada capítulo tem um notebook e o README do repositório traz um badge para abrir cada um no Google Colab.

**Fontes deste módulo:** [Hands-On Large Language Models](https://github.com/HandsOnLLM/Hands-On-Large-Language-Models) (Jay Alammar e Maarten Grootendorst, Apache 2.0).
