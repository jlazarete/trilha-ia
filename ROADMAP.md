# Roadmap

- [ ] Exercícios de revisão por módulo, criados a partir dos materiais linkados.
- [ ] Mapa visual da trilha (diagrama dos módulos e dependências).

Abra uma issue com o rótulo `roadmap` para votar ou sugerir novos itens.
